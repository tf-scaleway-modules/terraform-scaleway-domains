## Why

The `terraform` standards store moved to v2.1.0: one `required_version = ">= 1.11.0"` read by both OpenTofu and Terraform, both binaries pinned exactly in `mise.toml`, and a CI job proving Terraform compatibility (`terraform-providers`, `terraform-module-structure`, `terraform-repo-mise`, `terraform-repo-gitlab-ci`, `terraform-repo-precommit`). This module sits at `>= 1.10.7`, pins OpenTofu loosely (`1.11`), has no Terraform job, and its pre-commit Terraform hooks do not force `tofu`.

## What Changes

- **BREAKING**: `versions.tf` `required_version` goes from `>= 1.10.7` to `>= 1.11.0`; the same floor is applied to `examples/{minimal,complete,registration}/versions.tf` (today `>= 1.10`).
- Examples' scaleway provider constraint goes from `>= 2.86` to `~> 2.89`, equal to the root.
- `openspec/config.yaml`: `terraform` store `ref: v1.2.6` becomes `v2.1.0`; context line "required_version >= 1.10.7" becomes `>= 1.11.0`.
- `mise.toml`: `opentofu = '1.13.10'` (exact, was `1.11`), add `terraform = '1.17.2'` (exact).
- `.gitlab/release.yml`: `validate:opentofu` image `ghcr.io/opentofu/opentofu:1.13.10`; new `validate:terraform` (`hashicorp/terraform:1.17.2`) after it; added to `create:release` `needs:`.
- `.pre-commit-config.yaml`: `terraform_fmt`, `terraform_docs`, `terraform_tflint` get `args: [--hook-config=--tf-path=tofu]` (currently absent, so they would pick up `terraform` once installed).
- `.github/workflows/{ci,release}.yml`: `tofu_version` goes from `1.11.0` to `1.13.10` (no new GitHub job).
- Docs: README prerequisite and badge name OpenTofu >= 1.11.0 and Terraform >= 1.11.0; `AGENTS.md` does the same and adds `terraform init -backend=false && terraform validate` to the Commands line.
- Spec: `module-contract` "Supported tooling and providers" floor raised.

Release level (`terraform-versioning`): **major**, because `required_version` is raised. Upgrade note: consumers need OpenTofu or Terraform >= 1.11.0.

## Capabilities

None.

### Modified Capabilities
- `module-contract`: the supported-tooling requirement states `>= 1.11.0`, one constraint for OpenTofu and Terraform, and the older-toolchain scenario moves to 1.11.0.

## Impact

- Inputs/outputs: none change type, default or meaning.
- State: nothing changes; no resource, provider version or address moves.
- Files: `versions.tf`, `examples/*/versions.tf`, `mise.toml`, `.gitlab/release.yml`, `.pre-commit-config.yaml`, `.github/workflows/ci.yml`, `.github/workflows/release.yml`, `openspec/config.yaml`, `openspec/specs/module-contract/spec.md` (at archive), `README.md` (prose and badge, outside terraform-docs markers; the generated `terraform` requirement row is regenerated by pre-commit), `AGENTS.md`.
- Consumers on OpenTofu/Terraform 1.10.x must upgrade before taking this release.
